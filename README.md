# Pygame Projects

Projetos desenvolvidos em **Python com Pygame**, com foco em prática de programação, desenvolvimento de jogos 2D e experimentação de diferentes mecânicas.

## Projetos

### Jogos e experimentos

O repositório reúne diferentes projetos desenvolvidos durante meus estudos, incluindo:

* Jogos 2D
* Experimentos com movimentação e colisões
* Mecânicas de gameplay
* Sistemas de pontuação
* Interfaces e menus
* Testes com física e controles

Cada projeto possui sua própria pasta e pode apresentar diferentes abordagens e níveis de complexidade.

## Tecnologias

* **Python**
* **Pygame**
* Git / GitHub

## Como baixar

Clone o repositório:

```bash
git clone https://github.com/JudGB/Projects-Pygame.git
```

Entre na pasta:

```bash
cd Projects-Pygame
```

## Instalação

Certifique-se de ter o **Python 3** instalado.

Instale o Pygame:

```bash
pip install pygame
```

## Como executar

Entre na pasta do projeto que deseja testar e execute o arquivo Python principal:

```bash
python main.py
```

> O nome do arquivo de execução pode variar de acordo com o projeto.
